# LAN Server Properties

**[中文版 / Chinese README](README_zh-CN.md)**

This project is replicated from [LanServerProperties](https://github.com/rikka0w0/LanServerProperties)
All content is generated by AI

LAN Server Properties enhances the vanilla Minecraft LAN screen (the "Open to LAN" / "Multiplayer Options" screen) with more server options.

Downloads: [CurseForge](https://www.curseforge.com/minecraft/mc-mods/lan-server-properties/) · [Modrinth](https://modrinth.com/mod/P7dR8mSH) · [GitHub Releases](https://github.com/rikka0w0/LanServerProperties/releases)

## Features

With this mod installed, the vanilla LAN screen can additionally:

* Set a **custom port** instead of a random one.
* **Disable PvP**.
* **Disable the online mode**, so unauthenticated players can join the LAN server as well.
* Edit the settings of an **already-published server** from the same screen.
* Change the **maximum number of players**.
* Optionally use **genuine UUIDs** (from Microsoft/Mojang) in offline mode, which prevents inventory loss when a world is switched between online and offline mode.

### Minecraft 26.x layout

Since Minecraft 26.x the vanilla LAN options live in the pause menu → **Multiplayer Options…** screen (there is no separate "Open to LAN" screen anymore). On 26.2 the mod appends its own rows right below the vanilla *other players* settings (game mode / allow commands) in the same content column, plus a Save/Load preferences row on top of them:

* Save / enable preference rows
* Load preferences / PvP row
* Online mode / max players row
* Always-offline player list row

| NeoForge | 1.20.5 – 1.21.3 | built by the `neoforge/` subproject |

* Minecraft 1.20.5 and 1.21.2 have no Forge build (not supported by Forge itself at those versions).
* Older releases of this project support Minecraft 1.12.2 – 1.21.x (Fabric / Forge / NeoForge). In this branch the `fabric/` subproject was moved to the 26.x toolchain and now targets Minecraft 26.2 only, while `forge/` and `neoforge/` still target the 1.21.x era.

## Notes

* This mod is **client-only**; installing it on a dedicated server does nothing.
* Only the **LAN server owner** needs to install this mod.
* Vanilla clients can join your server even when you use this mod — although other mods you run may still prevent vanilla clients from joining.
* Installing this mod does not prevent you from joining other vanilla or modded servers.

## Dependencies

### Forge and NeoForge versions
Install Forge/NeoForge for the matching Minecraft version, then install this mod.

### Fabric version (26.2)
* Minecraft 26.2 requires **Java 25**.
* You need **Fabric Loader 0.19.3 or above**.
* **Fabric API** is optional but highly recommended.

## For developers

To modify and debug the code, import the `neoforge`, `forge` or `fabric` folder as a Gradle project (e.g. in Eclipse IDE) and run the `genEclipseRuns` task.

Windows users need to replace `./` and `../` with `.\` and `..\`, respectively.

### Code layout

* Since 1.17.1, the Fabric and Forge versions share as much common code as possible (official mapping based).
* Since 1.21, NeoForge support was added; coremods and access transformers were dropped completely and replaced by **Mixin**.
* Since Minecraft 26.1 the game is **no longer obfuscated**, which changed the Fabric toolchain: the `fabric/` subproject uses the new `net.fabricmc.fabric-loom` plugin **without mappings**, plain `implementation` dependencies, Gradle 9.5 and Java 25, and the LAN options are integrated into the vanilla `MultiplayerOptionsScreen`.
* The 26.2-adapted classes live loader-locally in `fabric/src/main/java` (e.g. `CommonWidgets`, `ConfigContainer`, mixins into `MultiplayerOptionsScreen` / `IntegratedServer` / `UUIDUtil`), while the shared `src/main/java` still holds the 1.21-era code used by the `forge/` and `neoforge/` builds.

### Compile Fabric artifact (26.2)
```
git clone https://github.com/rikka0w0/LanServerProperties.git
cd LanServerProperties/fabric
./gradlew build
```
The artifact is produced at `build/libs/lanserverproperties-<version>-fabric.jar`.

To debug in Fabric, one may need to create `run/config/fabric_loader_dependencies.json` with the following content:
```json
{
  "version": 1,
  "overrides": {
    "lanserverproperties": {
      "-depends": {
        "minecraft": "IGNORED",
        "fabricloader": "IGNORED"
      }
    }
  }
}
```

### To specify the JRE path

Minecraft Java requirements by version:

* Since 26.1, Minecraft (and the Fabric build of this branch) requires **Java 25**.
* Since 1.20.5, Minecraft requires Java 21.
* Since 1.18, Minecraft requires Java 17.
* Since 1.17, Minecraft requires Java 16.
* Older versions require Java 8.

Linux:
```
./gradlew -Dorg.gradle.java.home=/path_to_jdk_directory <commands>
```

Windows:
```
.\gradlew.bat -Dorg.gradle.java.home="C:/Program Files/Java/jdk-25" runClient
```
